# Roles

## coordinador (solo Felipe, no se puede tomar)
Reparte con `/repartir`, revisa los PR, hace merge a `main` y hace lo que los integrantes no puedan (skills o extensiones que ellos no tengan).

## integrante-1, integrante-2 e integrante-3 (este, solo si se suma una cuarta persona)
Hacen las tareas `tareas/<rol>-*.md`. El coordinador decide qué toca a cada uno (ej. uno backend/datos, otro frontend/presentación). Las skills las buscan según la tarea que les toque.
