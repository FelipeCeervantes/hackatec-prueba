# Hackatec – repo de PRUEBA (no es el real)

Cada quien usa **su propia cuenta** de Claude Code en **su propia laptop**. Nadie comparte contraseñas; solo compartimos este repo.

## Para los integrantes (app de Claude, pestaña Code: elige tu Escritorio como carpeta y pega esto)

```
Clona https://github.com/FelipeCeervantes/hackatec-prueba en mi Escritorio, entra a la carpeta y sigue su CLAUDE.md.
```

Tu Claude te pregunta cómo te llamas, te asigna el rol libre, instala lo que hace falta y te abre la oficina, donde tu bichito te explica lo demás. Después solo dile: **"haz mis tareas"**.

> Antes, acepta la invitación al repo que te llega por GitHub.

## Al terminar el evento
- Si quieres, cierra tu sesión desde el menú de tu cuenta en la app de Claude (Cerrar sesión).
- Felipe te quita como colaborador del repo.

## La oficina (panel dentro de la app de Claude)
Es el plugin `oficina@hackatec-prueba` de este repo. La primera vez que abras esta carpeta en la pestaña Code, la app te pide confiar en la carpeta e instalar el plugin: acepta. Desde ahí, cada vez que abras la carpeta aparece un panel junto al chat con la oficina pixel art del equipo. Solo se activa en esta carpeta. Si no aparece, escribe `/oficina` (o `/plugin install oficina@hackatec-prueba` si el comando no existe).

- Cada bichito muestra lo que hace su Claude: trabajando, pensando, esperando tu permiso, festejando al terminar, dormido o explorando el espacio si pasa mucho rato sin actividad.
- La barra bajo cada cuarto muestra el avance de su tarea (casillas de "Listo cuando") y el tiempo que falta según el `estimado`.
- Cuando alguien sube su rama, su bichito camina a entregarle el folder al coordinador. Si una tarea queda `bloqueado`, se pone triste. Cuando se une un avance a `main`, todos festejan.
- Botones: **Cerrar el día** (todos se van a dormir a la luna), **Modo pro** (lista sobria, sin mascotas), **Tamaño**, **Mi personaje** (color y accesorio; todo el equipo lo ve) y, solo para el coordinador, **Alerta** (todos se sorprenden, dan vueltitas y se juntan con él a escucharlo; sin sonido).
- **Desinstalar**: empacan y se van, y el plugin se apaga solo en tu laptop. Para activarlo otra vez, borra `.claude/settings.local.json`.
